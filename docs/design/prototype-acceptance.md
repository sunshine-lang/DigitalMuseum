## 如何体验

打开 [评审入口](index.html)，选择“从 F01 开始完整体验”。保持此目录及 `public/gallery/` 的相对位置；页面直接从本地文件打开，不需要启动后端。

1. F01 自动演示目录发现，按需指定示例目录；进入 F02 选择项目。
2. F03 主动读取历史，查看成功/失败/跳过，必要时只重试失败项。
3. 进入项目回顾页，加载演示模型配置、验证、核对范围，再主动生成。
4. 阅读概览、时间线和继续前须知。点击“浏览项目会话”或节点上的“查看原话与上下文”。
5. 对节点确认、修改、忽略或恢复。认可状态与当前适用性分别设置。
6. 点击“保存为新版本”。关闭页面或浏览器，再打开评审入口或项目列表，继续上次保存的项目。
7. 通过“检查新增会话”进入 F04。已保存版本作为更新前的基线，新候选不会改写它。

也可以直接打开[完整项目页](f05-f08-project-museum-prototype.html)。文件名沿用早期 F05–F08 阶段，页面现在已覆盖 F05–F12。

## 保存与隐私

- 版本真实保存在**当前浏览器的本地存储**，命名空间为 `dm-prototype:v1:`，按规范化的示例项目路径隔离。
- 一个版本包含回顾、人工修改、两种判定状态、会话元数据和入选原话快照。用户在原型里输入的修订也会随版本保存在本机。
- 仅保存演示模型名称与目录设置，不保存访问凭证。不读取真实 Agent 会话、调用真实模型或上传内容。
- 来源离线按钮是故障演示。非入选会话只有元数据时，不假装已经缓存完整原文。
- 设置中的清理只处理此原型自己的存储键，不操作 `~/.claude`、`~/.codex` 或正式 `data/`。

## 当前限制

这是已完成交互链路的浏览器原型。真实 Agent 解析、真实模型接口、正式证据 Blob/锚点存储、数据库迁移、服务端持久化与 Alpha 产品验收仍需独立开发。

浏览器保存已在本机 Chromium 中验证。不同浏览器或嵌入式浏览器对 `file://` 本地存储的行为可能不同；写入失败会明确提示。更换浏览器、文件位置或清理浏览器数据可能使原型存档不可用，不能当作正式档案备份。

旧页面链接如果只携带五条代表会话，会明确显示“仅携带代表样例”的提示。通过当前 F03 重新进入即可携带完整的已读会话目录。

既有 Figma 文件仍是早期视觉规范。此次完整交付是本地浏览器原型，没有将它描述为 Figma 原生可编辑组件或正式后端产品。
