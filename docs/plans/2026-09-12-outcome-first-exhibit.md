# 成果优先经历展品：本地展示样本

本轮意图来自用户的语音实施授权：第一读者是未来的自己。先让人看懂做了什么、推进到了哪里，打开以后再还原背景、选择、Agent 执行、结果与出处。

## 已落地的范围

- 延续项目纵深画廊的左图右说明。已有经历材料时，主标题改为具体工作，项目名退到标签；外层展示短概述、经历日期、来源类型和待确认状态。
- 详情默认展示目标 → 关键过程 → 结果，分清用户目标/选择、Agent 当时的交付说明和项目材料中的结果。原话可展开，保留五章阶段故事和原始记录两个阅读入口。
- 给现有私有草稿增加可选 `exhibit`，正文仍在 Git 忽略目录。API 校验所有引用、经历日期不超出故事范围，插画仅允许已知本地资产标识。旧草稿没有该字段时沿用原阅读方式。
- 提供 `/exhibition?exhibit=<story-id>` 直达入口。只按真实项目键定位，旧记录归属不清或链接不存在时诚实回退；日期筛选、勾选与静态导出仍使用原 event ID。
- 一张新纪念插画表达散落记录聚入档案入口。图中纸页不表示精确统计，不是历史现场。提示词不含私人原话、项目路径、日期或品牌；旧封面选择规则不变。

## 样本与边界

使用现有 DigitalMuseum 五章私有草稿中“项目记录归组”这一段经历。外层为具体工作概述，内层用当时的原话、助手交付说明和已保存的本地复核材料解释过程；涉及记录数量的结果明确写为当时的复核情况，不把历史数字冒充当前总量。

本轮没有全局重写/合并数据库事件，没有后台模型调用，没有自动挑选经历、价值打分或成功/失败分类，也没有本人确认、故事导出和市场验收。中止或未成功的尝试可以成为后续有依据的经历；未知结果不能当作失败。
