## 1. 产品概述

Digital Museum 是本地优先、开源的个人 Agent 会话档案馆。用户一键同步本机各 Agent 产品（Codex、Claude Code、pi、dsh、OpenClaw…）的会话转录，系统建立唯一档案库并以确定性规则解析为可追溯的经历（verified）；用户浏览档案时间线，将选定的窗口导出为自包含的静态展览网页——离线可看、可发朋友、可托管任意静态空间。

第一主题馆不变：「这一年，我和 AI 一起做了什么」。

## 3. 产品目标

### 3.1 北极星目标（双层）

> **近景（情绪价值）：把用户与 AI 协作的真实足迹，变成一眼可感的可视化回顾——「原来我和 AI 一起做了这么多」，且每一段都真实可溯。**
>
> **远景（行动价值）：从全部会话中淘出用户自己没意识到的重复流程，点亮沉淀为 skill 的机会——档案从回忆升级为生产力矿藏。**

真实性是情绪价值的前提：只有「全部真实发生、系统核实」，回顾才值得动情；也只有逐字锚定，重复流程才值得沉淀。

### 3.2 第一价值时刻（本阶段）

> 新用户打开工具，点一下「同步本机全部会话」，几秒后看到：
> 「原来这一年我在这些项目上和 AI 干了这么多天——全部真实发生、系统核实。」

### 3.3 第二价值时刻（本阶段）

> 「我的这段经历被做成了一份有设计感的网页展览，我愿意保存和分享它。」

### 3.4 第三价值时刻（下一阶段 · 方向）

> 浏览档案时，系统点亮一条线索：
> 「这段指令你在 12 个项目里逐字重复过——要不要把它沉淀成 skill？」
> 用户确认后，一段自己从未察觉的流程变成了工具。

## 4. 非目标

v0.2 非目标全部保留，新增：

- 不做人工整理工具（合并/拆分、批量确认）；
- 不做人工展签改写（展览文案完全由确定性底稿生成）；
- 不做多源导入的恢复（笔记/Git 已删除；恢复=另立阶段重新立项）；
- 不做后台常驻监听同步（仅打开时自动增量 + 手动再同步）。

## 6. 核心用户故事

- **US-02″ 一键同步**：作为新用户，我打开工具点「同步本机全部会话」，系统只读扫描各 Agent 产品的会话目录，直接建立档案并解析为 verified 经历，全程无表单、无确认。
- **US-11 浏览档案**：作为用户，我在时间线按时间/项目浏览经历，展开任意一段能看到逐字锚定的证据。
- **US-12 异议**：作为用户，我对某段记录存疑时可提出异议，系统记录我的判定并覆盖机器读数。
- **US-09 导出静态展览**：沿用 v0.2（选窗口、勾选事件、导出前敏感信息检查、单文件 HTML）。

## 11. 指标体系

自动化指标沿用；真实数据大考指标修订：

1. 一键同步 ≥6 个月全部会话转录，无失败无重复；
2. 事前手写关键事件，系统找回 ≥6/10；
3. 人工介入负担 ≈ 0（无核对队列；仅统计异议次数）；
4. P0（系统核实但实际错误）= 0；
5. 产出的静态展览愿意发给至少一位朋友。

## 13. 开放问题

1. OpenClaw 落地格式未知——等本机安装后探测；
2. 档案库整体备份/导出（原 Archive ZIP 能力）在新模型下的去留与时机；
3. 「阶段」视图的创建交互（浏览时保存窗口 vs 开展时定义）——S2 设计时定；
4. dsh 的 `zstandard` 依赖评审确认（ADR-0002 已记录理由）；
5. Skill 机会的确定性口径：逐字重复先行，「近重复」（编辑距离/词重叠阈值）算不算确定性读数；产出形态（浏览内建议 vs 独立页）与用户沉淀动作的闭环（导出为 skill 文件？仅提示？）——Phase 2 立项前定。
