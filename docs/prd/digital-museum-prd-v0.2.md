## 1. 产品概述

Digital Museum 是一个本地优先、开源的个人数字档案与策展工具。用户选择一个 3–12 个月阶段，导入自己与 AI 协作留下的文本痕迹——编码 Agent 会话、Git 提交、笔记、AI 聊天导出——系统以确定性规则从原始资料中提取可追溯 Claim，聚合为候选经历；用户核对关键内容后，将确认的经历导出为一份**自包含的静态展览网页**，可离线浏览、可发给朋友、可托管在任意静态空间。

第一主题馆仍为「AI 人生档案馆」：回答「这一年，我和 AI 一起做了什么」。

## 2. 背景与问题

### 2.1 用户现状（v0.2 修正）

目标用户（AI 编码 Agent 的重度使用者）在一个阶段内会产生：

- 数百个 Agent 会话（Claude Code `~/.claude/projects`、Codex `~/.codex/sessions`、WorkBuddy 等），散落在隐藏目录，从未被回顾；
- Git 提交与标签；
- 远端 AI 聊天（ChatGPT 导出 ZIP、各类 Chatbox 导出）；
- 零散的 Markdown/TXT 笔记。

这些痕迹可以分别回答：

```text
Agent Session：哪天、在哪个项目、和 AI 花了多少时间、说过什么
Git：真正交付了什么
Note：当时在想什么
AI Chat：当时在探索什么
```

但没有工具把它们组织成可信的经历回顾：IDE 不回顾历史，云厂商聊天记录分散在各平台，照片回忆类产品不理解代码工作。**v0.1 假设的「数百张照片」经真实数据检验是最小的一类素材；Agent 会话才是最大且从未被利用的一类。**

### 2.2 现有替代方案的不足

沿用 v0.1 第 2.2 节，另补一行：

| 替代方式 | 不能解决什么 |
|---|---|
| 各 Agent 自带的 history/resume | 只面向「继续上次任务」，不回答「我这段时间做了什么」；跨工具无整合 |

## 3. 产品目标

### 3.1 北极星目标（不变）

> 帮助用户以低于手工整理的成本，获得一组自己认可、可追溯、能重新唤起阶段记忆的人生事件。

### 3.2 第一价值时刻（修订）

用户导入 Agent 会话历史后，在发现页看到：

> 「原来我在这个项目上和 AI 干了这么多天——这些都是真实发生、机器核实过的。」

### 3.3 第二价值时刻（修订）

用户导出静态展览并发给朋友后：

> 「我的这一阶段被做成了一份有设计感的网页展览，我愿意保存和分享它。」

### 3.4 阶段目标

```text
Phase 0（进行中）：Evidence → Claim → Candidate Event → Event Review（已就绪）
Stage 6+：Agent Session 适配器逐个接入（Claude Code → Codex → 其他）
Stage 8：静态展览导出 + 视觉重投入
Stage 9：开源发布（License、README、示例数据）
Gate：维护者真实数据大考
```

## 4. 非目标

当前版本不做：

- 云端部署、公网上线、多用户与账号体系（**明确放弃 Cloudflare Worker 部署目标**）；
- 持续同步、OAuth、自动全盘扫描；
- 照片链路的新投入（2026-08-25 已整体删除适配器；HEIC、OCR、缺 EXIF 补录等需求恢复时另立阶段，从 stage-4 文档重启）；
- 移动端馆主 App、3D 展厅、公共社区、数字遗产；
- 无需用户审核的一键 AI 自传；
- 商业化验证。

## 5. 目标用户

**Primary Persona：AI 编码 Agent 重度使用的开发者**

- macOS/Linux，日常使用 Claude Code、Codex、WorkBuddy 之一以上；
- 机器上留有连续数月的 Agent 会话记录与 Git 仓库；
- 会写或会收集 Markdown 笔记（加分项，非必需）；
- 愿意运行本地开源工具（能启动本地 dev 栈）；
- 接受「先看系统找到什么，再核对关键内容」的节奏；
- 对「数据不出本机」有强偏好。

第一批用户就是维护者本人与早期开源 adopter——**dogfooding 是第一验收场**。

## 6. 核心用户故事

沿用 v0.1 US-01～US-05（创建阶段、导入、覆盖、审阅、保持 Unknown），新增/修订：

### US-02′ 导入 Agent 会话

作为用户，我希望粘贴一个项目路径，系统自动找到我在这个项目上的全部 Agent 会话（Claude Code / Codex / …），只读解析并生成候选经历；会话日期、条数、项目名是机器读数（系统核实），「这次会话在做什么」的概括等待我核对。

### US-09 导出静态展览

作为用户，我希望一条命令把当前阶段确认过的事件导出为一个自包含的静态网页目录（HTML + 内联数据，无后端依赖），我可以双击本地打开、发给别人或托管到任意静态空间。

### US-10 开箱即用

作为新用户，我希望 clone 仓库后按 README 三条命令跑起来，用自带示例数据 30 秒看到一份完整展览（无需先有自己的 Agent 历史）。

## 7. 产品范围

### 7.1 输入适配器（按优先级）

| Adapter | 状态 | 确定性读取范围 |
|---|---|---|
| Note（.md/.txt） | ✅ 已有 | 标题、日期、原文 |
| Work/Git | ✅ 已有 | 提交日（committer date）、标签、提交说明 |
| **Claude Code Session** | 🚧 Stage 6 | 会话时间戳、项目目录、用户/助手消息计数、用户首条消息原文 |
| Codex Session | Stage 7 | 同上（`~/.codex/sessions` rollout JSONL） |
| ChatGPT Export ZIP | 规划 | conversations.json：对话标题、时间戳、用户消息 |
| WorkBuddy / Chatbox 导出 | 规划 | 各自存储（SQLite/JSONL/导出文件） |
| Photo | 已删除（2026-08-25） | 见第 4 节 |

所有适配器遵守同一宪法：**确定性读数（时间戳、计数、路径）导入即 verified；一切概括、推断、标题改写一律 candidate；原文永不改写，逐字锚点不豁免。**

### 7.2 输出

- Event Review 工作台（已有）；
- **静态展览导出**：从本地库生成自包含静态站（Stage 8），视觉标准显著高于内部工具水准（这是产品的门面）；
- 展览导出内容只含用户勾选进入展览的事件，证据链细节默认不随导出公开（用户可显式选择包含）。

## 8. 真实性契约

完全沿用 v0.1 第 9 节与分级信任现行实现：

- 确定性读数 → `verified`（系统核实），不进人工核对队列，保留「对这段记录提出异议」入口；
- 推断性内容 → `candidate`，必须经人工核对；
- 用户审阅状态优先于机器读数，重复导入并入不复制；
- 模型将来引入时：输出只能产生 candidate 与逐字锚定的草稿，**永不产生 verified**。

## 9. 数据与隐私要求

- Local-first 不变：证据、事件、审阅记录全部在本机 SQLite 与 `data/uploads/`；
- Agent 会话是高度敏感数据（含源码、密钥风险）：只读、不修改源文件；证据文档只摘录用户消息首条与计数，**不整份复制会话内容**；导出展览前用户逐项确认可见内容；
- 开源仓库不包含任何个人数据（`data/` 永不入库）；示例数据必须是合成的。

## 10. 非功能需求

- 可追溯：Core Claim Grounding = 100%（沿用评测护栏）；
- 可恢复：审阅状态重启可恢复（已实现）；
- 视觉：静态展览在 390px/768px/1280px 三档宽度可读，Lighthouse 无红色项（Stage 8 细化）；
- 开源：MIT License；README 提供三命令快速上手；贡献与许可说明齐备。

## 11. 指标体系

自动化指标沿用 Phase 0 Scorecard（Grounding、Rejection correctness 等，评测护栏等值断言）。
**新增人工 gate（真实数据大考，Stage 9 前执行）：**

1. 维护者导入自己 ≥6 个月的全部 Agent 会话 + Git + 笔记；
2. 事前在纸上手写 10 件记得的关键事件；
3. 通过标准：系统找回 ≥6/10（Recall ≥60%）；核对负担可接受（≤30 分钟）；不出现任何「系统核实但实际错误」的事件（P0=0）；产出的静态展览愿意发给至少一位朋友。

## 13. 主要开放问题

1. 静态展览的视觉方向（题材气质：档案馆/杂志/暗色画廊——Stage 8 前定）；
2. 会话「在做什么」的一句话概括何时引入模型（规则：只产 candidate）；
3. 跨阶段人生总览何时做（数据模型已支持多阶段，UI 未做）；
4. Archive 一键导出/备份（对抗误删级联删除）何时插入——建议 Stage 8 前作为小切片。

## 14. 产品决策摘要

### 保持

- Slogan 与第一垂直（AI 成长档案）；
- 可信事件还原为核心、Event Review 为第一价值；
- 真实性契约与分级信任全部现行规则；
- Local-first、用户拥有数据。

### 收紧

- 目标用户收窄为 AI 编码 Agent 开发者，开源首发；
- 输入以文本痕迹为唯一主线，照片暂缓；
- 交付物以静态展览导出为终点，不做云部署。

### 最终产品判断（v0.2）

> **Digital Museum 是给 AI 时代开发者的个人历史学家：先把散落在隐藏目录里的协作痕迹变成可信的经历，再变成值得分享的展览。**

> **它依然必须先证明自己有资格说「这件事发生过」，之后才有资格说「这段人生可以这样讲」。**
