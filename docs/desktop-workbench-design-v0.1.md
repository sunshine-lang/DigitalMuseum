## 0. 结论先行：定向升级，不推倒

桌面端已通过五轮视觉验收（`design-qa.md`，1440×900 对照），纸感品牌、双色契约、铭牌系统是成熟资产。本方案**不重画品牌层**，只做四处定向升级：状态感知 hero、票根同构三步流、右栏 sticky、小签可读性。移动基准版（同日 v0.1）已确立"mobile base → desktop enhancement"原则，本文件是其中的 desktop enhancement 细则。

## 1. 现状盘点（改动依据）

| 组件 | 现状 | 问题 |
| --- | --- | --- |
| `mvp-hero` | H1 `clamp(42px,5vw,68px)` + 700px 副文案 + aside 数字侧栏（金色 3px 顶线、38px 数字、9px 标签），总高约 380px | 静态展示文案，有档案后首屏密度低；每天开馆看到的是同一句话 |
| `mvp-flow` | 横向三步链接，active = 卡底 + 金色 inset 3px 底线 | 与移动端票根导轨母题分裂 |
| `mvp-browse-view` | `2.2fr / minmax(300px,1fr)` 双栏 | 右栏随长卷宗滚动流失 |
| 小签 | 大量 9px JetBrains Mono | 低于桌面可读下限 |
| 深色 timeline 基础样式 | `--mvp-dark-*` 系 | 属静态导出午夜版契约，**不动** |

## 2. 布局方案（≥900px）

### 2.1 状态感知 hero（核心升级）

hero 改为两态，**空库保留现有大 hero**（首次开馆的品牌时刻），**有档案后收缩为紧凑开馆条**（380px → 约 220px）：

```text
┌────────────────────────────────────────────────────────────┐
│ ◉ 馆徽  Digital Museum        档案 · 展览 · 导出（顶栏不动） │
├────────────────────────────────────────────────────────────┤
│ ┌ 日期戳 ┐  把散落的 Agent 会话…        ┌ 2×2 mini 指标 ┐ │
│ │09·17  │  （副文案压缩为两行）        │ 卷 IX · 54     │ │
│ └───────┘  今日 6 条新记录 · 3 项目     │ 项目 23        │ │
│   [浏览当日卷宗]                        │ 待异议 2 …     │ │
└────────────────────────────────────────────────────────────┘
│ ① 同步 ┄┄ ② 浏览 ┄┄ ③ 展览   （票根导轨，同移动母题）    │
├──────────────────────────────┬─────────────────────────────┤
│ 卷宗时间线（左 2.2fr）       │ 选展准备（右 1fr，sticky） │
│ ── 九月 · IX ── sticky      │ 概览 digest                 │
│ [档案卡] [档案卡] …          │ 准备间 / 导出按钮          │
└──────────────────────────────┴─────────────────────────────┘
```

- **H1 降为 30px**（紧凑态），一行放馆名；副文案从 700px 长段落压为两行。
- **开馆日期戳**（签名元素，见 §5）放 hero 左上。
- 数字侧栏从纵排改为 2×2 mini 指标，与移动端 digest 同构。

### 2.2 三步流票根同构

`mvp-flow` **DOM 与文案不动**（E2E 断言零风险），只改视觉词汇：步骤间改虚线齿孔分隔（对齐移动票根导轨的撕口语言）；active 态在现有"卡底 + 金色 inset 底线"上增加 ink 填充序号圆（现有 `button.active > span` 已是 ink 填充，保留）。≥900px 时移动票根导轨隐藏、此横轨生效——**同一母题，两种落位**。

### 2.3 浏览视图微调

- `2.2fr / 1fr` 网格保留；右栏加 `position: sticky; top: 76px`（顶栏高 + 间距）。
- 卷宗月分隔（`mvp-timeline-date` 铭牌）在长滚动时 sticky，与移动端行为一致。
- ≥1280px 内容宽 `min(1280px, calc(100% - 64px))` 保留，无新增布局。

## 3. 配色方案

**零改动**。token 表见移动基准版 §3（paper `#efeae3` / ink `#1a1714` / blue `#3e5871` candidate 虚线 / gold `#8c6d3f` confirmed 实心 / green `#47755e` verified / rust `#9c4a2f` 异议）。桌面不新增任何颜色，深色午夜导出样式（`--mvp-dark-*`）属静态导出契约，不进入工作台。

## 4. 字体方案

三角色制与移动版一致（Playfair Display + Songti SC 展示 / Source Serif 4 正文 / PingFang SC + JetBrains Mono 标签）。桌面字阶：

| 层级 | 现状 | 本方案 | 说明 |
| --- | --- | --- | --- |
| H1（紧凑态） | 42–68px | 30px | 空库首开馆保留原 clamp |
| 副文案 | 16px / 700px 宽 | 15px / 两行 | |
| hero aside 数字 | 38px | 34px | 转 2×2 后缩小一档 |
| 档案卡题 | 24px | 24px | 不动 |
| 正文 | 16px | 16px | 不动 |
| Mono 小签 | 9–9.5px | **10.5px 下限** | 桌面下限低于移动的 12px，仍高于现状 |

## 5. 签名元素：开馆日期戳

hero 左上放一枚大号日期戳铭牌（宋体日·月 + Mono 年份，1.5px 墨色描边），沿用现有 `mvp-timeline-date` 铭牌语言放大。它做三件事：把"每天开馆"变成可感知的仪式；与移动端焦点卡的日期戳同构（同一母题）；取代 hero 里已经没人读的静态长文案，成为每天真正变化的信息（今天 + 当前卷宗号）。**克制**：全页仅此一枚大日期戳，卷宗内日期铭牌维持原尺寸。

## 6. 质量底线

- DOM 结构与文案不动（`mvp-flow`、hero 文案节点保留，仅 CSS 层级切换两态）；
- `prefers-reduced-motion`：sticky 无动画；票根齿孔为纯 CSS 边框，无动效依赖；
- `focus-visible` 金描边沿用；键盘 Tab 顺序不变；
- 静态导出（午夜编年阅读版）与展览页零影响。

## 7. 验收标准

1. 1440×900 有档案态首屏：顶栏 + 紧凑 hero + 票根三步流 + 第一条卷宗全部可见（现状 hero 一屏占不满、卷宗需下滚）；
2. 空库首开馆：现有大 hero 原样呈现；
3. 右栏与月分隔 sticky 生效，滚动不丢失选展面板；
4. 现有 21 项 E2E 全过（DOM/文案未动，纯视觉改动不应破坏断言）；
5. `npm run test:local`、typecheck、lint 通过；截图对照流程按 `design-qa.md` 惯例归档。

## 8. 实施切分

1. **S1**：hero 紧凑态 + 开馆日期戳（CSS 两态切换，风险最低）；
2. **S2**：三步流票根齿孔与 active 视觉；
3. **S3**：右栏 sticky + 月分隔 sticky；
4. **S4**：小签 9→10.5px 全局修正 + 截图验收归档。
