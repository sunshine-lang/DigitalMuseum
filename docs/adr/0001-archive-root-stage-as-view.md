# 档案库为根，阶段降为视图

---
status: accepted
date: 2026-08-25
---

## 背景与决定

v0.2 的「阶段」（用户手选的 3–12 个月窗口）是数据属主兼导入过滤器：用户必须在看到任何数据之前声明时间范围。2026-08-25 的第一性原理梳理确认这是倒置——时间戳内在于会话数据本身（Codex 路径按日期分层、pi 文件名带 ISO 时间、转录首行含 `timestamp`），同步即得时间结构，无需预先声明。

**决定：数据的唯一属主是档案库（Archive）**——首次同步建立档案，同步只并入不覆盖、幂等；「阶段」降级为对档案的命名时间窗视图，删除视图不删除数据；「重新开始」等于清空档案库。3–12 个月政策从导入硬约束移为展览策展时的建议。

## 备选方案（已否决）

- **自动切阶段、模型不动**：切分口径任意（按季？按活跃度？），跨阶段体验突兀，保留属主复杂度。
- **单一大阶段覆盖全部**：折中但两头不沾——既要放宽政策又保留级联删除的复杂度。

## 后果

- schema 重构：occurrence / event 的 `stage_id` 外键属主关系解除，阶段表退化为视图引用（窗口 + 名字）；「删除阶段级联清库」语义随之消亡。
- 同步幂等（重复导入并入不复制）从适配器行为升格为档案库的一等契约。
- 开发中定型、无存量用户，本次重构不写数据回填迁移（直接改模型重建）。
