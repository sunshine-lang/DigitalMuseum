# 单燃料极简：Agent 会话为唯一第一等燃料

---
status: accepted
date: 2026-08-25
---

## 背景与决定

v0.2 保留了笔记、Git、ChatGPT 导出等多源路线图。真实数据大考（2026-08-24）、新用户走查与第一性原理梳理（2026-08-25）表明：本机 Agent 会话是体量最大（389 个转录）、结构最好（时间戳 + 项目归属内生于格式）、且从未被任何工具利用的一类燃料；多源入口反而稀释核心体验。

**决定：第一阶段唯一的第一等燃料是本机 Agent 产品的会话转录**，口径从严——以人机对话为主体、带时间戳与项目归属（cwd）的 JSONL（Codex、Claude Code、pi Agent、dsh、OpenClaw 等）。调试转储（hermes `request_dump_*`）与进程心跳（WorkBuddy）不算转录，不接入。

随之删除（连代码带测试，参照照片谱系的清剿先例）：笔记上传（`note-development-v1`）、Git 导入（`git-evidence-v1`）、合并/拆分整理、人工展签行内改写。主流程收敛为极简三步：**同步 → 浏览 → 展览**。同步即解析：确定性适配器直接产出 `verified` 事件，无人工确认环节；「对这段记录提出异议」入口按真实性宪法保留。

## 备选方案（已否决）

- **保留多源路线图**：稀释单燃料体验，每条链路都要维护测试与 UI。
- **笔记/Git 恢复为二级入口**：与「同步即建档」的零门槛叙事相悖。
- **宽口径（痕迹也算燃料）**：调试转储无项目归属、语义弱、含敏感头字段。
- **引入模型解读会话（「AI 解析」读法 B）**：违反「模型输出只产 candidate、永不 verified」的宪法；且「会话本身是真实记录」恰恰是确定性 verified 的论据，不需要模型。

## 后果

- e2e 主链路（以笔记导入、合并/拆分为骨架）需重写为会话流。
- 「愿意分享」（上次 Gate 唯一未过项）全部押注确定性叙事底稿的升级——风险集中，已知并接受。
- 为 dsh 的 zstd 转录引入 `zstandard` 依赖（Python 3.11 标准库无 zstd 解压）；这是本轮唯一新增第三方依赖。
- pi 适配器与 Codex 几乎同构（转义目录 + JSONL + 首行 cwd），复用 `agent_session_evidence` 渲染。
